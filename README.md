# COCOA 2026 — Programa completo

Programa completo del Congreso Colombiano de Astronomía (CoCoA 2026),
del martes 1 al viernes 4 de septiembre de 2026, en Bogotá.

## Ver el programa

### https://forero.github.io/cocoa-2026-programa/

| Día | Sede |
|---|---|
| Martes 1 sep | UDistrital · Aduanilla de Paiba |
| Miércoles 2 sep | Instituto de Metrología (IMC) → OAN-UNAL |
| Jueves 3 sep | Universidad de los Andes |
| Viernes 4 sep | UNAL · Observatorio Astronómico Nacional |

Página estática (un solo archivo HTML, sin dependencias) con navegación por día
y por salón, línea de tiempo y búsqueda por ponente, título o código.

Programa solo del jueves: https://forero.github.io/cocoa-2026-jueves/

Fuente: [Programa y Cronograma CoCoA 2026](https://accefyn.com/microsites/nodos/astroco/wp-content/uploads/2026/08/Programa-y-Cronograma-CoCoA-2026-2.pdf) (versión 2).

## Archivos

- `index.html` / `cocoa_programa_completo.html` — la página del programa.
- `qr_cocoa26.pdf` — hoja con códigos QR: charlas del día 3 y enlace para subir presentaciones.
- `Puerta_*.pdf` — señalización para las puertas de los salones (LL002, ML513, W102).
